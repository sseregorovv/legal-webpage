# Сергей Егоров — юридическая практика

Персональный сайт для GitHub Pages: https://esslaw.ru/.

Это обычный статический сайт. Установка Node.js, npm и отдельная сборка для публикации не требуются. HTML, CSS, JavaScript, фотографии и калькулятор находятся в этом репозитории.

## Как обновить сайт через GitHub Desktop

1. Откройте репозиторий `legal-webpage` в GitHub Desktop. Рабочая ветка — `main`.
2. Нажмите **Fetch origin**. Если программа предлагает **Pull origin**, сначала получите последние изменения.
3. Откройте папку репозитория через **Repository → Show in Explorer** и измените нужные файлы в редакторе.
4. Вернитесь в GitHub Desktop и просмотрите вкладку **Changes**.
5. В поле **Summary** напишите, что изменили, например «Обновил описание услуг», и нажмите **Commit to main**.
6. Нажмите **Push origin**. GitHub Pages обновит сайт после обработки коммита.
7. Проверьте https://esslaw.ru/. Если видна старая версия, выполните принудительное обновление страницы: **Ctrl+F5**.

Статус публикации можно посмотреть на вкладке **Actions** репозитория на GitHub.

## Настройки GitHub Pages

В **Settings → Pages** используйте:

- **Source:** Deploy from a branch.
- **Branch:** main.
- **Folder:** /(root).
- **Custom domain:** esslaw.ru.

Если действующий сайт уже использует эти настройки, повторно менять их не нужно.

## Как в дальнейшем добавить PDF

Для материалов можно создать папку `materials` и положить туда PDF с коротким латинским именем, например `arbitration-court-timezones.pdf`.

В разделе материалов добавьте название, описание и дату проверки данных, а затем ссылки:

```html
<a href="materials/arbitration-court-timezones.pdf" target="_blank" rel="noopener">Открыть PDF</a>
<a href="materials/arbitration-court-timezones.pdf" download>Скачать PDF</a>
```

После этого опубликуйте изменения тем же способом через **Commit to main → Push origin**. Первый материал уже добавлен в «Мои проекты»: справочник часовых поясов судов и его интерактивная версия.

## Как обновить справочник судов

При обновлении PDF замените файл `materials/arbitration-courts-timezones.pdf`, затем обновите массив в `assets/courts-data.js`. Поле `moscowOffset` — разница с Москвой в часах, например `4` для Красноярска. `city` — город суда; `aliases` — дополнительные названия для поиска; `note` — важное примечание. После изменения количества судов обновите число в описаниях на главной странице и странице инструмента. Часовые пояса судов берутся из справочника и не предназначены для исторических расчётов ранее 2026 года.

## Аналитика и поисковая индексация

- Основной адрес сайта: `https://esslaw.ru/`. У каждой HTML-страницы указан собственный `rel="canonical"`; ссылки на главную ведут на `/`.
- `sitemap.xml` находится в корне сайта и перечисляет восемь страниц. При добавлении или удалении страницы обновляйте карту и canonical. В карту включайте только предпочтительные адреса, без `/index.html` для главной и калькулятора.
- `robots.txt` разрешает обход и содержит ссылку на `https://esslaw.ru/sitemap.xml`.
- Счётчик Яндекс Метрики: `114683680`. На семи страницах установлен код владельца, блок `noscript` находится в `body`.
- В калькуляторе используется тот же счётчик через существующее согласие пользователя. Вебвизор и карты кликов отключены; URL расчёта с именами и возрастом в параметре `s` не передаётся. Не добавляйте туда второй стандартный счётчик.
- В главной странице восстановлены два прежних метатега `yandex-verification` из версии до обновления дизайна (коммит `7e3f752`). Они должны сохраняться при последующих обновлениях. Актуальный статус прав проверяйте в Яндекс Вебмастере.
- После публикации проверьте доступность `/sitemap.xml` и `/robots.txt`, затем отправьте URL карты в Яндекс Вебмастер и Google Search Console. Подтверждение прав и цели настраиваются в кабинетах сервисов; код сайта сам по себе не подтверждает подключение Вебмастера.
- Яндекс Форма находится на другом домене. Метрика и событие отправки подключаются отдельно в настройках самой формы.
